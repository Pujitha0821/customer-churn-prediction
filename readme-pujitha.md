# Customer Churn Prediction & Retention Dashboard

**Objective**: Predict customer churn and identify high-risk segments to reduce revenue loss.

**Dataset**: IBM Telco Customer Churn (7,043 records)  
**Source**: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

### Key Insights
- Customers with month-to-month contracts are 3.5× more likely to churn
- Fiber optic users + no tech support = highest churn risk
- Predicted $480K annual revenue save possible with targeted retention

### Tech Stack
- Python (Pandas, Scikit-learn, Matplotlib/Seaborn)
- Models: Logistic Regression, Random Forest, XGBoost
- Target: 82–85 % accuracy, >78 % recall on churn class

### Files
- `churn_analysis.ipynb` → Full EDA + model training
- `Telco-Customer-Churn.csv` → Dataset
